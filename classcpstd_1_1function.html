template<typename Signature>
class cpstd::function< Signature >

Type-erased callable, as std::function.

In STL mode this is std::function. Otherwise it stores a copy of the callable on the heap (new). Calling an empty function is undefined (std::function throws bad_function_call); test it with operator bool first.
