template<class Category, class T, class Distance = cpstd::ptrdiff_t, class Pointer = T*, class Reference = T&>
struct cpstd::iterator< Category, T, Distance, Pointer, Reference >

Base class that declares the five iterator member types, like the (C++17-deprecated) std::iterator.

CPSTL keeps its own in both modes so deriving from it never triggers deprecation warnings.
