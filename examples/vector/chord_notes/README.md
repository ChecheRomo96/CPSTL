# Chord notes

Extend a C major chord with an octave.

Arduino and desktop run the same scenario. Values labeled simulated do not
come from attached hardware. Read the printed inputs, operations and results
in order.

## Example output

Observed on desktop with CPSTL mode enabled. Arduino prints the same scenario.

```text
Extend a C major chord with an octave.
Initial C major MIDI notes: 60, 64, 67
After push_back(72), adding the octave: 60, 64, 67, 72
Notes in the final chord: 4
These are MIDI note numbers; this example prints them and does not play audio.
```
